## Уточнение псевдокода, 7 ноября 2026 года

Прочитать [отчёт](pseudocode-refinement.md). В отдельной копии Ghidra уточнены
десять функций: четыре пары из оценки объединения и два x87-helper.
Исправлены стековые входы и аргументы косвенных вызовов; минимальная структура
явно показывает поле +0x10. Прежний вывод о потерянной записи был ошибкой
интерпретации `int* + 4` и снят. Ghidra всё ещё печатает `ROUND` для x87-конверсии
с RC=11; в проекте/экспортах предупреждение об усечении к нулю.

Команды: `& tools/ghidra/refine-pseudocode.ps1`, затем та же команда с `-Verify`,
`node tools/research/verify-refinement.cjs` — прошли. Все 14 образцов manifest
совпали до/после обоих запусков; десять C/листингов совпали после повторного
открытия read-only; байты проверены по PE. Сводка:
`analysis/pseudocode-refinement.json`. Проект: `research/ghidra/s01-refined/SmutaRD.gpr`;
экспорты: `decompiled/s01-refined/`; журналы: `research/evidence/s01-refined/`.
Исходный проект/экспорт сохранены. Драйвер использует локальные пути из
`research/evidence/decompilation/s01-initial/run.json`.
Проверки Parser PowerShell, `node --check`, 33 относительных ссылок,
`git diff --check` и исключения локальных материалов прошли.

Далее — цикл и загрузка DAT отдельно для двух игр, затем уточнение типов

## Принятые решения

- Smutabor достаточно для исследования; поиск непатченных оригиналов не нужен.
- Windows, Linux, PortMaster; SDL2; два самостоятельных рендера:
  оригинальный программный и OpenGL с совместимостью OpenGL ES 2.
- Современный ввод и графическая обвязка реализуются заново: WASD
  с мауслуком либо геймпад с двумя стиками (движение / обзор и прицеливание).
- Игровые данные — из папок соответствующих игр; точный набор файлов
  определить в S01. Для «Смуты» опционально — из первого трека CD-образа.
- Музыка «Смуты» — CD Audio из BIN+CUE либо папка треков OGG/FLAC.
- Сейвы и раздельные данные игр; совместимость со старыми сейвами пока не установлена.
- Русский и английский текст обеих игр; озвучка вне задачи локализации.
- Новый код — MIT, данные игр не распространяются с портом.
- Будущие опции: алебарда без заряда с согласованной визуальной дальностью;
  использование озвучки Raising Dead в «Смуте» и наоборот. Исходное поведение
  и озвучка остаются по умолчанию. Эти опции не блокируют базовый порт.

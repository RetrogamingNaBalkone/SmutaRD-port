# План разработки

## Принятая основа

SDL2-порт двух игр для Windows, Linux и PortMaster. Исследуются имеющиеся
сборки Smutabor; поиск непатченных версий не является зависимостью.
Исходные ограничения ввода и платформенной графики не воспроизводятся.
Требования и правила — [AGENTS.md](../AGENTS.md).

## Критерии будущего порта

- Обе игры работают с отдельно предоставленными данными.
  Точный необходимый набор файлов из папки каждой игры определяется по `originals/`.
- Два рендера проходят проверки на одних игровых сценах;
  программный путь не требует OpenGL, аппаратный соответствует GLES 2.
- Обе игры поддерживают WASD с мауслуком; на геймпаде левый стик управляет
  движением, правый — обзором и прицеливанием.
- Музыка «Смуты» воспроизводится из аудиотреков BIN+CUE либо из папки
  треков OGG/FLAC. Соответствие номеров треков и игровых событий
  определяется исследованием, без привязки к выдуманной схеме именования.
- Сохранения проходят цикл запись/загрузка, данные игр не смешиваются.
- Интерфейс и игровые тексты доступны на русском и английском.
- Подтверждены сборки и запуск на целевых платформах, ограничения описаны.

## Будущие опциональные возможности

- Для «Смуты» — источник игровых данных из первого трека CD-образа.
  Это отдельная возможность от воспроизведения CD Audio из BIN+CUE.
- Патчи алебарды: убрать заряд и согласовать дальность удара с визуальным
  представлением. Конкретные изменения определить после исследования механики.
- Озвучка Raising Dead в «Смуте» и озвучка «Смуты» в Raising Dead,
  с отдельно предоставленными ресурсами соответствующей игры.

Эти возможности не блокируют базовый порт. Исходное поведение оружия
и исходная озвучка сохраняются по умолчанию. Обмен существующей озвучкой
не является переводом или созданием новой озвучки.

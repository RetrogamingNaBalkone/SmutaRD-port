# План разработки

## Принятая основа

SDL2-порт двух игр для Windows, Linux и PortMaster. Исследуются имеющиеся
сборки Smutabor; поиск непатченных версий не является зависимостью.
Исходные ограничения ввода и платформенной графики не воспроизводятся.
Требования и правила — [AGENTS.md](../AGENTS.md).

## Критерии будущего порта

- Обе игры работают с отдельно предоставленными данными.
- Два рендера проходят проверки на одних игровых сценах;
  программный путь не требует OpenGL, аппаратный соответствует GLES 2.
- Игровые действия доступны с клавиатуры/мыши и геймпада.
- Сохранения проходят цикл запись/загрузка, данные игр не смешиваются.
- Интерфейс и игровые тексты доступны на русском и английском.
- Подтверждены сборки и запуск на целевых платформах, ограничения описаны.

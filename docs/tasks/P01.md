# P01 — Позадачный план разработки субагентами

Статус: завершена.

## Цель и границы

Составить исполнимый план оставшихся исследований и разработки двух игр:
задачи для субагентов, зависимости, приёмка, handoff после каждой задачи
и промежуточная оптимизация двух рендеров. Реализация порта сюда не входит.

- [Шаблон паспорта](TEMPLATE.md), [правила проекта](../../AGENTS.md).

  [оценка объединения](../unified-port-assessment.md),

## Работы

1. Сверить текущее состояние с документами репозитория.
2. Разбить оставшуюся работу на задачи с ролями, входами и критериями готовности.
3. Определить порядок передачи результатов, безопасный параллелизм и приёмку.
4. Включить повторные измерения и оптимизацию программного и GLES 2 рендеров.
5. Проверить ссылки и согласованность, обновить план и handoff.

## Критерии готовности

- Каждая задача имеет ID, исполнителя, зависимости, результат, приёмку и адресата handoff.
- Охвачены требования обеих игр и всех целевых платформ; опции отделены от базы.
- Оптимизация следует за проверкой поведения и содержит измеримые условия приёмки.
- Не заявлены несуществующие реализация, сборки и игровые проверки.
- Следующий субагент получает конкретную исследовательскую задачу внутри S01.

## Результаты и проверки

Создан [план из 43 поручений](../agent-plan.md), обновлены общий план,
handoff, S01 и указатель паспортов. По уточнению пользователя сначала
принимается Windows-версия (A33), затем начинаются Linux/ARM/PortMaster.
Оптимизация выделена в A14, A18, A19, A29, A37 и A38.

Фактические проверки 7 ноября 2026 года:

- PowerShell: `Get-Content -Raw -Encoding UTF8`, разбор Markdown-ссылок через
  `[regex]::Matches`, проверка `Test-Path` в шести затронутых документах:
  все 61 относительная ссылка существует (итоговая проверка после обновления паспорта).
- PowerShell: сравнение ID строк через `Compare-Object` с диапазоном A01–A43:
  ровно 43 уникальные задачи, пропусков нет.
- JavaScript через PowerShell here-string `| node`: чтение UTF-8 через `fs`,
  проверка пяти непустых полей каждой строки и диапазонов зависимостей:
  43 полные карточки, 98 явных связей, все зависимости предшествуют потребителям.
  Первая попытка проверки завершилась ошибкой regex из-за кодировки Unicode
  при передаче в stdin; повтор с `\u2013` прошёл.
- `git diff --check`, просмотр `git diff -- docs/plan.md docs/handoff.md
  docs/tasks/README.md docs/tasks/S01.md` и `git status --short`: замечаний
  к diff нет, изменены только документы задачи; новые файлы плана/паспорта прочитаны.

Реализация, сборки, игровые проверки и измерения производительности не выполнялись.
Паспорта A-задач создаются перед исполнением; численные бюджеты и оборудование
будут определены в A14/A36. S01 остаётся в работе. Коммит не создавался.

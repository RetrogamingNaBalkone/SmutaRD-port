# Паспорта задач

Текущая задача: [S01](S01.md). Общий порядок — [план](../plan.md),
состояние проекта — [handoff](../handoff.md).

Перед реализацией создавать паспорт по [шаблону](TEMPLATE.md).
Паспорт должен позволять продолжить работу в новом чате: входы, результат,
критерии готовности, команды, доказательства, ограничения и следующий шаг.
Не отмечать задачу завершённой только по наличию файлов.

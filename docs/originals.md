# Исходные комплекты Smutabor

## Принятая база

Имеющихся комплектов Smutabor Patch достаточно для начала восстановления.
Поиск непатченных оригиналов не является условием разработки.
`originals/` хранится локально, не изменяется и не включается в Git или поставки.

| Игра | Каталог относительно корня | Основной EXE | Основной архив |
| --- | --- | --- | --- |
| «Смута: Ожившие мертвецы» | `originals/smuta_modern_20261013/smuta_modern/` | `SMUTA.EXE` | `SMUTA.DAT` |
| Raising Dead | `originals/Raising-Dead_modern_20261013/Raising-Dead_modern/` | `Rd.EXE` | `data/Rd-1.dat` |

Точные размеры и SHA-256 — в [manifest](../analysis/originals-manifest.json).
Он включает игровые EXE, установщики, Register.exe, дополнительный EXE,
DLL, DAT и README_MODERN.TXT для идентификации описаний патча.
Дата в названии каталога — часть имени комплекта, не проверенная дата выпуска.

## Известные изменения

Следующие сведения взяты из `README_MODERN.TXT` каждого комплекта.
Это заявления сопровождающей документации; анализ кода ещё не проводился.

### «Смута»

- DISPDIB.DLL с CD для запуска игры.
- smuta_xp_fix для звука под Windows XP/Vista.
- WASD и обзор мышью.
- Запись smuta.ini в каталог игры вместо Windows; SETUP.EXE без требования
  прав администратора.
- Музыка CD-версии в OGG с воспроизведением без диска.

### Raising Dead

- Согласно README, изменено только управление.
- WASD по физическим клавишам, одновременный горизонтальный и вертикальный
  обзор мышью без удержания правой кнопки, стрельба левой кнопкой.
- Совместная работа движения, стрейфа, бега, обзора и стрельбы.
- Сохранены стрелки, бег на Shift/Caps Lock, выбор оружия цифрами
  и остальные назначения, не конфликтующие с WASD.
- Отключены конфликтующие служебные назначения S+цифры и D.

Рядом есть `Rd.EXE.before-input-patch`. Имя указывает на копию до патча ввода;
полная оригинальность и отсутствие других изменений не установлены.
Это дополнительный материал, а не обязательная база порта.

## Использование

Игровое поведение и программный рендер исследуются по этим образцам.
Современный ввод и платформенная графическая обвязка создаются через SDL2,
без воспроизведения старых ограничений. Проверенные выводы должны ссылаться
на конкретный SHA-256, а не на абстрактную «оригинальную версию».

Не запускать игры непосредственно из `originals/`: для экспериментов делать
локальные копии по [протоколу исследований](research.md).

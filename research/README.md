# Локальные исследования

Этот README отслеживается Git. Остальное содержимое `research/` игнорируется:

- `ghidra/` — постоянные проекты Ghidra.
- `evidence/` — полные доказательства, журналы, снимки и трассы.
- `experiments/` — рабочие копии игр и воспроизводимые опыты.

Полные экспорты декомпиляции хранятся в корневом `decompiled/`, также вне Git.
Исследования не складывать в `build/` и не включать в пакеты порта.
Выводы публиковать в `docs/`, компактные результаты — в `analysis/`,
инструменты — в `tools/`. Перед очисткой сохранять необходимые доказательства.

См. [протокол](../docs/research.md) и [описание образцов](../docs/originals.md).

# SmutaRD-port

SDL2-порт игр «Смута: Ожившие мертвецы» и Raising Dead («Смута 2»)
для Windows, Linux и PortMaster.

## Состояние

Подготовлены репозиторий и документация. Реализация движка, декомпиляция,
сборочная инфраструктура и игровые проверки ещё не начаты.
Основой исследования служат имеющиеся сборки Smutabor Patch;
поиск непатченных версий не требуется для начала работ.

## Цели

- Два самостоятельных рендера: восстановленный оригинальный программный
  и OpenGL, совместимый с OpenGL ES 2.
- WASD с мауслуком либо геймпад с двумя стиками, переназначение действий.
- Музыка «Смуты» из CD-образа BIN+CUE или папки треков OGG/FLAC.
- Данные из папок игр; для «Смуты» также опционально из первого трека CD-образа.
- Сохранения и раздельные пользовательские данные двух игр.
- Русские и английские игровые тексты: исходный русский текст «Смуты»
  и английский Raising Dead, а также недостающие переводы.

Ввод и платформенная графическая обвязка будут реализованы через SDL2.
Воспроизводить старые ограничения этих подсистем не требуется.
OGDoK служит ориентиром организации и возможностей порта.

Будущие опции: алебарда без заряда с дальностью удара, соответствующей
визуальному представлению, и использование озвучки одной игры в другой.
Они не заменяют исходное поведение по умолчанию.

## Данные игр и лицензия

Игровые данные пользователь предоставляет отдельно. Локальные комплекты
хранятся в `originals/`; их содержимое не изменяется, не включается в Git
и не поставляется с портом. Рабочий способ подключения данных будет описан
после реализации загрузчика.

Новый код проекта распространяется по [MIT](LICENSE). Эта лицензия
не распространяется на оригинальные игры, их исполняемые файлы, музыку,
графику, тексты и другие сторонние материалы. Права на них принадлежат
соответствующим правообладателям.

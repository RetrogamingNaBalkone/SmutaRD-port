# Компактные результаты

В Git хранятся небольшие проверенные таблицы, инвентаризации и сводки,
не содержащие игровых ресурсов или полных декомпиляций.

- [originals-manifest.json](originals-manifest.json) — относительные пути,
  размеры и SHA-256 исполняемых образцов, DLL, DAT и описаний Smutabor.
  Дата инвентаризации — 6 ноября 2026 года. Это идентификация файлов,
  а не доказательство их формата или поведения.

Для будущих результатов указывать точный образец, происхождение,
команду получения и ограничения. Крупные отчёты сохранять в локальном
`analysis/local/`, оставляя здесь компактные сводки со ссылками на доказательства.
Правила — [протокол исследований](../docs/research.md).
